# Evidence

One folder per week: `week-01/`, `week-02/`, and so on.

File naming: `YYYY-MM-DD_short-description.ext`

Index everything in `/logs/evidence-index.md` during the Friday session.

Screenshots must show a visible timestamp — a system clock, a console timestamp column,
or a terminal prompt with the date. An undated screenshot proves nothing about when the
work happened.
