# Attempt 1 (superseded)

This folder holds the first source-environment build. It was built on Ubuntu 26.10,
which AWS MGN does not list as a supported operating system, so the build was
discarded before any replication started. The files are unchanged originals and are
kept as evidence of the incident and of the troubleshooting done along the way.

The valid source environment is in `../attempt-2/` (Ubuntu Server 24.04.3 LTS,
kernel 6.8.0-147-generic).

The IP addresses in these file names are the DHCP addresses of attempt 1 and are not
the addresses of the final build.
