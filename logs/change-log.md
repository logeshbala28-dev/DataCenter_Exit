# Change Control Log

Any change to scope, cost, schedule or a committed objective is recorded here.
Baselines are never edited directly — a change request and a re-baseline record are
created instead.

| ID | Date raised | Description | Trigger | Schedule impact | Cost impact | Decision | Date decided |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

**Decision options:** Approved / Approved with conditions / Deferred / Rejected.

Record the reasoning, not just the outcome. A change log that shows only approvals
suggests no real constraint was ever applied.
