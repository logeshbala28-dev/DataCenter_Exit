# Cost Baseline: Pathfinder Wave (Wave 1)

**Status:** DRAFT for author review. Becomes a frozen baseline once committed, before the AWS Replication Agent is installed on any source server.
**Prepared:** 2026-11-05
**Relates to:** `pm-baselines/pre-registration.md`, E-8 (total AWS cost, pathfinder wave: $20)
**Budget alerts:** $15 and $30 (see `logs/cost-log.md`)
**Drafted with AI assistance (Claude); reviewed and adopted by the author.**

## Purpose

E-8 was committed as a single figure of $20. This file shows what that figure is made of, so that after the pathfinder the actual bill can be compared line by line and the variance explained. It does not replace E-8.

## Scope and assumptions

| # | Assumption |
|---|---|
| 1 | Region us-east-1. Linux instances, on-demand pricing. No Savings Plans or credits. |
| 2 | Replication runs about 14 days (336 hours) from agent install to teardown. This is a planning figure, not a measurement. |
| 3 | One replication server (t3.small) serves all three source servers. MGN creates it; its size comes from the replication settings template. |
| 4 | Staging volumes mirror source disks: 3 x 20 GB = 60 GB, gp3. |
| 5 | Used data on the three sources is 26,343,444,480 bytes (E-2), about 26.3 GB. This sizes the snapshots. |
| 6 | Test and cutover instances are t3.small, running 24 hours in total per server across test launch, the failed cutover and the corrected cutover. |
| 7 | Launched volumes exist for 7 days before teardown. |
| 8 | The MGN service charge is $0: 336 hours per server is inside the 2,160 free hours (90 days) that start at agent install. |
| 9 | Inbound data transfer to AWS is free. $2.00 is allowed for outbound data and the optional cross-region recovery test. |
| 10 | The landing zone (Wave 0) has no recurring charge while idle. There is no NAT gateway. |

## Estimate by component

| Component | Calculation | Cost (USD) |
|---|---|---|
| Replication server, 1 x t3.small | 0.0208 x 336 h | 6.99 |
| Replication server root volume, 8 GB gp3 | 8 GB x 0.08 x 14/30 | 0.30 |
| Staging volumes, 60 GB gp3 | 60 GB x 0.08 x 14/30 | 2.24 |
| Staging snapshots, about 26.3 GB, two full-set equivalents | 2 x 26.3 GB x 0.05 x 14/30 | 1.23 |
| Public IPv4 address on the replication server | 0.005 x 336 h | 1.68 |
| Test and cutover instances, 3 x t3.small, 24 h each | 3 x 0.0208 x 24 | 1.50 |
| Launched volumes, 60 GB gp3, 7 days | 60 GB x 0.08 x 7/30 | 1.12 |
| Public IPv4 addresses on launched instances | 3 x 0.005 x 24 | 0.36 |
| Outbound data and DR allowance | allowance | 2.00 |
| **Subtotal** | | **17.42** |
| Contingency, 20% | 0.20 x 17.42 | 3.48 |
| **Total with contingency** | | **20.90** |

The bottom-up expected cost is $17.42. With 20% contingency it is $20.90, which is consistent with the E-8 figure of $20 and sits between the $15 and $30 alerts.

## What drives the number

The replication server and its public IP are 8.67 of the 17.42, about half, and they scale with how long replication runs. If replication runs 28 days instead of 14, the estimate roughly rises by the time-based lines (about 6.99 + 0.30 + 2.24 + 1.23 + 1.68 = 12.44 more). Shortening the time between agent install and teardown is the main lever on cost.
