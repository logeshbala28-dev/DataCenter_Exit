# Runbooks

Written before execution, never after.

- `cutover-runbook.md` — minute-by-minute, with owner, duration and validation per step
- `rollback-plan.md` — including the explicit rollback decision point
- `dr-recovery-procedure.md` — with timing instrumentation defined in advance

A runbook without a decision point produces extended outages, because nobody wants to
abandon a cutover that feels nearly finished.
